## 🚀 About

Sad-MD adalah bot WhatsApp berbasis Node.js dengan sistem custom menggunakan Baileys versi modifikasi sendiri.

Bot ini memiliki:
- Multi fitur
- Pairing Code Login
- Auto Backup
- RPG System
- Anti Bot
- Auto Shalat
- Welcome System
- Pterodactyl Features
- Subdomain Features
- Plugin System
- Dan berbagai fitur lainnya

---

# ⚠️ IMPORTANT

## ❌ Jangan Ubah File Ini

```bash
index.js
```
Mengubah file utama dapat menyebabkan bot error atau tidak bisa berjalan.

---

📥 Installation

```bash
# Clone Repository

git clone https://github.com/Putrazaubdillah/SadMD

# Masuk Folder

cd REPOSITORY

# Install Dependencies

npm install

# Jalankan Bot

npm start
```
